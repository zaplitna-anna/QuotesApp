#Quotes App - Практична робота №1

**Основні сценарії:** 
- перегляд випадкової цитати, 
- додавання власної, 
- фільтрація за категорією, 
- збереження в обране.

## Предметна область: 2 сутності

1. **Quote** - окрема цитата з id, текстом, необов'язковим автором та категорією.
2. **QuoteCollection** - колекція цитат із методами додавання, пошуку та фільтрації.
